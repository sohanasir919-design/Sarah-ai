Place your rigged female avatar here as:  app/src/main/assets/models/sarah.glb
- Include an idle animation (index 0) - it is looped automatically.
- For lip-sync, export with a mouth morph target (e.g. "mouthOpen"/"jawOpen" as morph target index 0).
  Morph target 0 is driven by audio amplitude while Sarah speaks.
Sources: Ready Player Me (GLB with blendshapes), Mixamo (animations), Sketchfab (CC models).
If the file is missing the app shows a placeholder orb so everything else still works.
